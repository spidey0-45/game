# ✊✋✌️ Rock Paper Scissors

A simple Rock Paper Scissors game built as my first version of the project. This application lets players compete against the computer in the classic game using a clean and interactive interface.

Although this is an early version, it helped me strengthen my understanding of front-end development, JavaScript logic, and DOM manipulation. More features and improvements are planned for future updates.

## 🌐 Live Demo

👉 https://spidey0-45.github.io/game/


## ✨ Features

- 🎮 Play against the computer
- 🤖 Random computer move generation
- 🏆 Instant win/lose/draw result
- 📱 Responsive design
- ⚡ Fast and lightweight
- 🎨 Simple and user-friendly interface

- Game statistics

These features are planned for future releases.
